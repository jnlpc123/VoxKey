# VoxKey 1.1.0-preview.1 验证记录

日期：2026-10-27。此版本为统一主线预览版；用户明确要求本轮跳过剩余实机测试。

## 已完成

- 从当前根目录源码构建 Sony helper 和完整 APK，编译成功；APK v2/v3 签名验证通过。
- 147 项逻辑检查通过：15按键会话、9末尾标点、22导航与云协议、9录音缓冲、9排队取消、36恢复与设置合并、20迁移ACL／数据格式／防覆盖、4模型流完整性、11设备路由、12索尼恢复退避与SYNC。
- 100 次立即 ADB OPEN／数据／CLOSE 往返和 RSA 授权签名检查通过。关闭测试 socket 时的一条 Socket closed 输出来自测试连接退出，不代表检查失败。
- Sony API29+ 旧 Binder 反射不兼容问题经复核，主线已限制该驱动到API26–28，边界检查覆盖25／26／28／29和F5隔离。
- 独立复核存储、唤醒、设备路由、Binder UID 校验及最小迁移桥，最终未发现P1／P2。
- 迁移桥仅含三个 Java 类，无输入法／桌面入口、网络或录音权限、模型及第三方识别库。签名权限、精确包名及签名检查保留。读取旧配置格式与 F5 1.0.0、Sony 1.0.2 一致；新版UID重新加密并回读验证。
- 发布源码不含签名私钥、用户密钥、本机调试身份、专有固件或模型本体。

## 本轮较早完成的 F5 实测

以下实测发生在最终统一包构建之前，不作为最终包已验收的声明。

1. 一体版迁移报告 `migrationDone/settingsVerified/keyVerified/hasKey=true`，旧设置、云端模式及密钥回读校验成功。
2. 用户确认迁移后的百炼云端实体语音输入正确填字，没有弹出当贝助手。日志记录成功、11字、约2.94秒，不记录文字或密钥。
3. 用户确认本地输入“流浪地球”正确。日志解码约1.67秒。
4. 用户用遥控器正常关机约10秒后再开机，电脑只重连读取、没有执行恢复写入：一体版PID仍为23478，默认IME为一体版，语音键服务与Aerial服务保留，独立恢复助手无进程。属于正常遥控器关机／唤醒，不是断电冷启动。
5. 存储优化构建覆盖安装后，F5原生模型初始化成功；私有重复模型缓存 `legacyModelBytes=0`，`modelReady=true`，迁移校验与密钥存在标志保持true。此次首次资产校验0.716秒、原生初始化3.969秒、合计4.686秒；优化前同轮首次提取与加载7.384秒。不同后台负载，不能据此保证固定加速比例。
6. 后续用户关闭投影仪，并要求停止本轮设备测试。此后没有安装最终统一预览包、操作设备或卸载旧应用。
