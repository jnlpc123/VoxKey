# 1.1.0-preview.2 发布验证

日期：2026-10-29。版本码112，沿用原统一包名与发布签名。本次发布为GitHub预览版；未操作任何设备。

## 变更

- 当贝识别支持厂商／品牌字符串的Dangbei与中文当贝，不再只检查DBF5；品牌信息缺失的固件可在引导里手动启用标准输入框接管。索尼明确排除标准后端，保留Sony辅助。
- 标准语音键自动模式支持135、219、231，也可手动选一种。仍要求实体键、非密码编辑器、可见VoxKey面板；导航／确认／Home不拦截。
- 按下时记录键码所有权，改变设置或失去输入焦点后仍消费自己对应的松开事件，其他键的松开不结束录音。
- 首次缺少必要设置时展示引导，可从主界面随时重开：麦克风运行时授权／应用详情、启用输入法、选择当前输入法、无障碍设置、接管开关、键码选择、测试入口、可选恢复与ADB授权说明。
- 不支持的系统设置Intent回退到系统设置；拒绝麦克风后可进入应用详情；授权状态回到页面自动刷新。不自动覆盖系统无障碍列表。
- 设备诊断仅显示厂商／品牌／型号／系统、连接状态和最近收到的135／219／231实体语音键，不读取编辑文字、密钥或设备序列号。
- 当贝恢复可在识别出的其他当贝型号上手动启用，标为实验功能；Android7不启用API26服务，避免反复崩溃。可选恢复不计入普通输入的必备设置。

## 检查

- 178项逻辑检查通过：28按键／会话、9标点、22导航与云协议、9录音缓冲、9排队取消、36恢复合并与唤醒、20迁移、4资产完整性、11设备路由、12Sony恢复／SYNC、18设置顺序／当贝识别／API边界。
- 100次本机模拟ADB往返及RSA签名检查通过。
- 最终APK构建成功，v2/v3签名校验通过；SetupActivity非导出。
- 独立复核发现并修复API24–25恢复服务兼容问题，复核后无P1/P2。
- 沿用既有离线模型和APK资产加载方式，无第二份私有模型缓存。
